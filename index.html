SKYCODE / DOCUMENTATION

Your AI harness.
Cloud or local.

Install once, then use skycode from anywhere. Connect local models, Claude, OpenAI, OpenRouter, and more from one terminal UI.

1

Install SkyCode

Open PowerShell and run:

irm https://raw.githubusercontent.com/imacul/skycode/main/install.ps1 | iex

Open your terminal and run:

curl -fsSL https://raw.githubusercontent.com/imacul/skycode/main/install.sh | sh
The installer places SkyCode under your user profile, installs dependencies, and creates a global skycode command. After installation, use skycode update for future updates.
2

Run SkyCode

Start a fresh session:

skycode

Open your saved chat history:

skycode resume
3

Update SkyCode

SkyCode checks for updates automatically when internet access is available. Offline and local-model use continue normally if GitHub cannot be reached.

Check for an update without installing:

skycode update --check

Install the latest version:

skycode update

Enable automatic installation of future updates:

skycode update --auto

Disable automatic installation:

skycode update --no-auto
Automatic installation is opt-in. By default, SkyCode only notifies you when a newer version is available.
4

Add a local model

Inside SkyCode, run:

/addlocal

SkyCode supports Ollama, LM Studio, llama.cpp, and OpenAI-compatible local servers. For your llama.cpp server, use:

http://127.0.0.1:8080

COMMANDS

Useful commands

/addlocalAdd or update a local AI server.
/addcloudAdd Anthropic or OpenAI.
/openrouteAdd or update OpenRouter.
/historyList saved chats with dates and activity.
/resume 1Resume a saved chat by number.
/copyCopy the latest assistant reply.
/modelInspect or switch models.
/newStart a new conversation.
HISTORY

Your chats stay local

Conversation history is stored on your machine under ~/.skycode/conversations.json. Provider settings are stored under ~/.skycode/settings.json.
